# Step-by-step quick guide

1. **Zoom-in** on the map to make the interactive grid appear.
2. **Click** on any grid cell to select a location.
3. **Use the calendar selector** above the map to select the date(s) of the event.
4. **Make sure** that the correct event type (*Hot / Cold*) is selected.
5. **Click *Continue*** to proceed to the results page.

**Please note**: For season sensitive events (e.g off-season frosts or heatwaves that might be considered as mild in absolute terms...) you may want to set the *Restrict to same dates* selector to *yes* for results better suited to this usecase.
