# Step-by-step quick guide

1. **Zoom-in** on the map to make the interactive grid appear.
2. **Click** on any of the available grid cell to select a location.
3. **Use the calendar selector** above the map to select the date(s) of the past event of interest.
4. **Make sure** the correct event type (*Hot / Cold*) is selected.

**Please note**: For season sensitive events (e.g off-season frosts and heatwaves that might otherwise be mild in absolute terms...) you may want to set the *Restrict to same dates* selector to *yes* for more relevant results.
